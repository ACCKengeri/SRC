The signature — "ACC" wordmark dissolve

Set in the display face under an SVG gooey filter (feGaussianBlur → feColorMatrix), the letters melt and reform on a slow ~8s loop as the divider between the welcome text and the domains. Freezes to a single static "ACC" under prefers-reduced-motion. ~1.5 KB inline, no JS library.

Motion legend

  • Smooth / inertia scroll — Lenis (~4 KB), deferred. Off under reduced-motion and on touch.
  • Heading & line reveals — build-time word-spans + IntersectionObserver + CSS stagger, fire once. No-JS fallback shows the final state.
  • Image hover — CSS only: resting desaturate + ink scrim → scrim lifts, colour restores, 1.02 scale, 320ms.
  • Footer hairlines — draw in left-to-right on scroll.

Budget: < 7 KB gzipped of client JS, all deferred and gated. No GSAP, no Lottie, no WebGL.
